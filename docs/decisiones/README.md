> Desde la 036, la columna de contexto incluye las alternativas descartadas. Una decisión superada no se reescribe:
> se anota «Superada por la decisión NNN». «Implícita» marca una alternativa que el código y los commits no
> nombran como tal: se deduce de lo que la decisión evita.
